# 🌐 gamesonthestage.fr

[![Site Officiel](https://img.shields.io/badge/Site_Officiel-gamesonthestage.fr-4DE2AB?style=for-the-badge)](https://gamesonthestage.fr)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)

> Site vitrine officiel de l'association **GOTS** (Games On The Stage), spécialisée dans la production d'événements e-sport et gaming (notamment la **TSLAN**).

---

## Fonctionnalités

- **Gestion des événements :** Actualités de l'association, archives et contact.
- **Performance & SEO :** Interface fluide et optimisée pour le référencement naturel.
- **Responsive Design :** Ergonomie adaptée à tous les types d'écrans (Desktop, Tablette, Mobile).

---

## Stack Technique

- **Frontend :** React 19, Vite
- **UI & Dynamic BG :** OGL (WebGL)
- **Hébergement :** Auto-hébergé sur serveur dédié, sécurisé via le réseau **Cloudflare**.
